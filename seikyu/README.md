# APLink 請求・入金管理 — Java 移行検証版

Java 21 / Spring Boot 3.5。ブラウザーUIとJava APIを単一JARで提供します。
**本番移行完了版ではありません。楽々FrameworkⅡは含まれていません。**

## 実装した業務

- 得意先・業者・商品・銀行・科目・内訳マスタ：登録、編集、無効化、検索、CSV取込。
- 出荷伝票：登録、請求前訂正、マイナス数量の記録。
- 請求：得意先別・締日別集計、重複防止、発行・再発行記録、残高照会、確認用の簡易請求書。
- 入金：部分入金、複数請求への配分、手数料・値引・現金・手形の分離、過剰消込防止。
- 仕入・実在庫・定時請求・小口現金・支払：登録、照会、基本自動仕訳。
- 貸借一致チェック、Excel出力、月次ロック、更新履歴。
- ログイン、管理者・閲覧者権限、CSRF対策、同時更新検知。

## ビルドと検証

Java 21とMaven 3.9以上を用意して、このディレクトリで実行します。

```sh
mvn verify
```

`target/seikyu-1.0.0-SNAPSHOT.jar` を生成します。テストには架空データのみを使用します。

## サーバー起動

運用者がJavaサーバーで起動します。GitHub Pagesでは実行できません。

```powershell
$env:APLINK_ADMIN_PASSWORD = '<16文字以上の管理者パスワード>'
java -jar seikyu-1.0.0-SNAPSHOT.jar
```

管理者IDの既定は `admin`。初期パスワードはありません。16文字未満では起動しません。
既定はループバック8080番、H2ファイルDB `./data/seikyu`。
このフォルダーは永続化してください。再起動しても業務データは残ります。

| 環境変数 | 用途 |
|---|---|
| APLINK_ADMIN_USER / APLINK_ADMIN_PASSWORD | 管理者ID・パスワード |
| APLINK_VIEWER_USER / APLINK_VIEWER_PASSWORD | 閲覧専用ID・パスワード。パスワード省略時は無効 |
| DATABASE_URL | PostgreSQL例：`jdbc:postgresql://db:5432/seikyu` |
| DATABASE_USER / DATABASE_PASSWORD | DB認証 |
| PORT / SERVER_ADDRESS | 待受ポート・アドレス |
| COOKIE_SECURE | HTTPS運用時は `true` |

本番はPostgreSQL、HTTPSリバースプロキシ、秘密情報管理、バックアップを構成してください。
`compose.yaml` はアプリとPostgreSQLの構成例です。Dockerでの実機検証は今回実施していません。

## データ保全

更新要求はリビジョン一致時のみ受け付けます。失敗した登録・CSV取込は全件ロールバックします。
業務JSONと監査ログの保存は同一DBトランザクションです。
H2のバックアップはサーバー停止後に `data/` をコピーします。PostgreSQLは `pg_dump` 等を使用し、別環境で復元を検証してください。

## 配布物

公開配布物には原本Excel/PDF、旧ソース、OCR、取引・銀行口座データ、認証情報を含めません。
詳細な調査根拠は元の作業フォルダーの `analysis/` に保存しています。
