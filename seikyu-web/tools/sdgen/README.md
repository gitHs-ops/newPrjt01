# sdgen：画面設計書（seikyu-web_画面設計）の再生成ツール

画面設計書を、**画面そのもの（ローカル検証サーバ）＋補足入力＋規則** から作り直す。規則や画面が変わったら、`sdgen\rules.py`・`sdgen\style.py` か `補足入力\<画面ID>.xlsx` を直して `run_all.bat` を実行する。

> 現在は P4（全 44 画面シート＋目次・業務フロー・変更点、次の版での保存）。V16（2026-11-01）はこのツールで作って保存した最初の版。生成した各シートは最新の版と文字の並びで照合する（`work\build\compare_<シート名>.txt`）。

## 1. 構成

| ファイル | 役割 |
|---|---|
| `run_all.bat`・`setup.bat` | 一括実行・準備（ASCII のみ） |
| `screens\<画面ID>.json` | 画面の開き方（メニュー・ボタン）と、項目を取り出す区画（エリア名・範囲・取り出し方）。区画ID・エリア名は補足入力と同じ |
| `補足入力\<画面ID>.xlsx` | 画面から取れない内容。シート「構成」＝画面シートを上から並べた部品、「表」「図」「項目」「手順」＝その中身。書き方はシート「説明」 |
| `補足入力\_共通.xlsx` | 目次・業務フロー・変更点の内容。「目次」＝シートの並び・目次に載せるか・版ごとの 追加／更新、「業務フロー」＝業務と画面ID・決定事項、「変更点」＝人が書く変更点、「文」＝題・説明・注 |
| `sdgen\rules.py` | 画面の項目 → 設計書の列の規則（表示区分・必須・形式・桁数・初期値。桁数は DB 定義 `test\schema\schema.sql` も見る） |
| `sdgen\style.py` | 見た目の規則（文字・色・罫線・列幅・行の高さ） |
| `sdgen\front.py` | 目次・業務フロー・変更点のシート（既存の版から読む・作る） |
| `sdgen\docdiff.py` | 画面シートの差分（前の版 → 今回。画面項目・基本情報・操作手順・見出し・画面図） |
| `sdgen\menu.py` | メニュー（サイドバー）とシートの対応の検査 |
| `sdgen\sheet.py` | 設計書の画面シートを部品に分ける（migrate と差分で使う） |
| `capture.py` | 画面を開いて項目（DOM）と画面図（PNG）・帳票（Excel）を取り出す → `work\capture\`。全画面のときはメニューの木も（`_menu.json`） |
| `report_img.py` | 帳票 Excel の1ページ目を PNG にする（Excel を使う） |
| `build.py` | 補足入力の「構成」の順に画面シートを組み立てる。画面項目は 取り出した項目＋補足入力＋規則。前に目次・業務フロー・変更点を置く → `work\build\画面設計_生成_YYYYMMDD.xlsx` |
| `finish.py` | 矢印を描く（Excel を使う） |
| `compare.py` | 既存の最新版（`SDGEN_DOC_DIR` の V 番号最大）と文字の並びで比べる → `work\build\compare_<画面ID>.txt` |
| `publish.py` | 作った設計書を設計書フォルダに次の版（`seikyu-web_画面設計_YYYYMMDDVn.xlsx`）として保存し、その版の 追加／更新 の列と「<版>変更点」を `_共通.xlsx` の履歴に書く（同じ名前のファイル・Excel で開いているときは保存しない） |
| `migrate.py` | 既存の設計書のシートを補足入力に移す（画面を追加するときに1回）。図は `sdgen_fixed\` に取り出す。`migrate.py 共通` は目次・業務フロー・変更点を `_共通.xlsx` に |
| `C:\myPrjt01\seikyuPrjt01\sdgen_fixed\` | 固定画像（補足入力の 図 で `fixed:ファイル名`）。大きいので git に入れず設計書の横に置く（`SDGEN_FIXED` で変更） |

## 2. 使い方

1. 準備（最初に1回）：`setup.bat`
2. ローカル検証サーバを起動しておく（既定 `http://127.0.0.1:8098`。本番には接続しない）
3. パスワードを環境変数で渡す（リポジトリには置かない）：`set SDGEN_PASSWORD_FILE=C:\...\pw.txt`
4. 実行：`run_all.bat`（全画面）／`run_all.bat SC-PUR-01`（1画面）
5. 結果：`work\build\画面設計_生成_YYYYMMDD.xlsx`、指摘 `画面設計_生成_YYYYMMDD_report.txt`（「メニュー:」の行がメニューとの対応）、全メニューとシートの対応 `menu_check.txt`、照合 `compare_*.txt`
6. 版として保存（中身を確かめてから）：`python publish.py` → 設計書フォルダに次の版。保存後に作り直すと、その版と全シート一致し、次の版の列・変更点は出ない（変更が無いため）

| 環境変数 | 意味 | 既定 |
|---|---|---|
| `SDGEN_BASE` | ローカル検証サーバ | `http://127.0.0.1:8098` |
| `SDGEN_USER` | ログインID | `doc-admin` |
| `SDGEN_PASSWORD`／`SDGEN_PASSWORD_FILE` | パスワード／それを書いたファイル | （必須） |
| `SDGEN_DOC_DIR` | 設計書の置き場所（照合・migrate の元） | `C:\myPrjt01\seikyuPrjt01` |
| `SDGEN_WORK` | 作業フォルダ | `tools\sdgen\work` |

## 3. 項目の決まり方

- 並び：補足入力の「項目」シートの順。
- 区分・必須・初期値・桁数・形式：補足入力が**空欄なら画面から自動**（`rules.py`）、値があればその値。
- 画面にあって補足入力に無い項目は「（補足入力なし）」で載せ、report に出す（画面が変わったことの検知）。補足入力にあって画面に無い項目も report に出す。
- 画面から取らない区画（帳票の列、データの状態でしか出ないモーダル、廃止済み）は補足入力の値だけで載る。

## 4. 目次・業務フロー・変更点

- 版：設計書フォルダの最新版（V 番号が最大）を「前の版」、その次（例 V16）を「次の版」とする。
- 目次：`_共通.xlsx` の目次の並びで、載せる＝○ のシート。画面名・機能NO は各シートの補足入力の表から。V13・V14… の列は `_共通.xlsx` の値、**次の版の列は前の版との差分から自動**（前の版に無いシート＝追加、違いがある＝更新。違いが無ければ列を作らない）。
- 業務フロー：`_共通.xlsx` の行。新システムの画面が空欄なら画面IDのシートの画面名から作る。次の版の列は、行の内容が変わったとき・画面IDのシートが更新されたときに 更新（前の版に無い行は 追加）。前の版に業務フローが無ければ、それより前の版と比べる。
- 変更点：`_共通.xlsx` の変更点を版ごとに「<版>変更点」シートに。次の版のシートは、同じ版の行（人が書いた根拠つきの変更点）＋差分（自動）。差分は 画面項目（追加・削除・変更）、基本情報・説明の表、操作手順、見出し・文、画面図（差替え・追加・削除。並びは見ない）。
- メニューとの対応（report の「メニュー:」の行）：画面名がメニューに無い／開いた画面のメニューが画面名と違う／表示中のメニューにシートが無い／目次に載っていないシート／業務フローの画面の表記がメニューに無い。

## 5. 手で直した図・文の扱い

- 図を差し替えたいとき：補足入力の 図 の「画像」を `fixed:ファイル名`（`sdgen_fixed\` に置く）。画面から撮り直すなら `capture:撮影名`（screens の shot の name。`＋` でつなぐと縦に並べる）。
- 矢印：図 の「矢印の終点」に矢印を引く先の図（シートの上からの番号）、起点x・y／終点x・y に図の中の位置（0〜1）。
- 設計書を Excel で直接直した文は、次の再生成で消える。文は補足入力で直す。

## 6. 画面を取り出すときの約束

- データを変えるボタン（登録・実行・確定・取消する・発行・削除・保存）は押さない。モーダル・確認は開いて `escape` で閉じる。
- 画面図は実際の画面だけを写す（サイドバーのメニュー・上のバー（パンくず・利用者・ログアウト）は写さない。2026-11-05）。shot に `el` があればその要素、`clip` があればその範囲から本文（`#content`）の外を切り落とす、どちらも無ければモーダルが開いていればモーダル、なければ本文全体。
- 取り出し方（mode）：`fields`（ラベル付き入力欄）、`controls`（検索条件など。ラベルの無い欄は並び順で対応）、`thead`（一覧の列見出し）、`linegrid`（明細表。見出しの無い列は飛ばす）、`message`（モーダルの文）。
